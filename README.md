# 北京敏捷社区活动粉丝群

这是一个面向北京敏捷社区参与者的微信群邀请页面。访问者可以扫描页面中的二维码加入社区微信群；当二维码失效时，也可以通过页面展示的电话、微信或邮箱联系社区志愿者。

## 官方网站
[北京敏捷社区网站](http://wwww.agiletour-beijing.com)

## 页面预览

![北京敏捷社区活动粉丝群二维码](images/agile-bj-wechat.jpg)

## 功能特点

- 展示北京敏捷社区微信群二维码
- 提供二维码失效后的志愿者联系方式
